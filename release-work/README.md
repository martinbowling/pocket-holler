# Historical full-game proposals

These chapter scripts and host-side checks were prepared before native integration. The full game is now implemented and emulator-tested in `../native/`: R01–R24, P01–P12, all three companions and the dawn reunion. See the repository README and `native/docs/qa-report.md` for the current cartridge and delivery evidence.

The earlier relocated-project authorization issue was resolved within the authorized workflow by copying source back to the original sibling `native/` working folder. Completed, verified files are synchronized to `src/native/`; the server authorization was not changed.

`full_game_support.py`, `creek.py`, `ridge_hollow.py` and `prepare_integration.py` are historical proposal inputs. Do not replay them as installers over the current project. The integrated helpers are under `native/tools/full_game/`. `verify_proposals.py` checks source contracts, not native engine behavior; its historical reports must not be treated as cartridge proof. Approximate composition WAVs were previews, distinct from native APU audio in the final video.

The existing private owner repository contains the source release. Public visibility, a blanket content license and physical cartridge flashing remain separate decisions.
