All native progression above uses ordinary controller inputs, neutral waits and actual menu choices. Memory and paired symbols are read only for state assertions and legal navigation. No memory writes, teleport, injected initial RAM or save-state shortcut sets progress. Both the regression and video journals are tied to the exact ROM hash. Detailed inputs, hashes, native screenshots and audio QA are retained in the release evidence archive; runtime temporary files are excluded from Git.

A real collision issue was caught during integration: hidden gate actors still collided in the native engine. Hide scripts now explicitly disable collision, while only intended blocking actors re-enable it when shown. The final route traverses all repaired passages. Ability and inspect dispatch use banked custom events; compiled-out automatic A interaction prevents duplicate/swapped input behavior.

The full game is implemented and delivered in the existing private owner repository. Cosmetic simplifications and remaining review checks are listed in `known-issues.md`; human timing is needed to assess the handoff's 60–90 minute target. The automated route duration is not a first-player pacing result. The historical opening ROM and its separate `opening-qa-report.md` remain preserved, with their original evidence identity.
