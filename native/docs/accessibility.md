# Opening comfort and access

Mandatory clues use text or shapes; Reveal marks use rays. Color adds information. The opening has no combat, health loss, countdown, random encounters, forced reflex sequence or companion harm. Wrong windscreen choices are freely reversible. Return to Camp and porch hints are available.

Audio Off suppresses the original beeps. Reduced Scares stores the preference; this opening already uses restrained text-only unease, with no flashes or jump cuts. A separate scare variant is not implemented yet. Fast Text changes native text speed on scene entry. Settings and saved states were exercised through ordinary inputs; actual output has not been listened to.

Dialogue is manually wrapped to sixteen characters per line and three lines per page. Static fit passes, and genuine 160×144 frames are retained. Menus use A confirmation and B cancellation. Start/Select closing behavior needs refinement.

Before acceptance, two fresh players should play without coaching until stuck. One run uses Audio Off and Reduced Scares. Record first-light and porch-save time, hints, missed targets, confusion, tone and readability. Native frames and automation do not substitute for human review.
