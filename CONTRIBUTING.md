# Contributing

Open `native/project.gbsproj`. Preserve distributed metadata and resource IDs. Actor/trigger symbols and script-event IDs must be unique, including copied branches. Keep room and variable registers current.

Prefer native editor or semantic tools; use the smallest validated source correction when a tool cannot represent a necessary fix. Keep editable art sources. Do not replay development actor-creation batches over the current project.

Build, record the exact hash, retain relevant input-driven emulator evidence, inspect actual 160×144 output, and update known issues. Save tests use copied files. Preserve unrelated local work and user play.

Identify asset authorship, sources, modifications and compatible licenses. Do not add family photographs, private biographical information, ripped game assets, proprietary boot ROMs or uncertain third-party content. Agree on contribution licensing with the owner before outside contributions; the proposed split is not an approved blanket grant.

Expansion waits for opening review. Public names/likenesses, title clearance, final credits, licenses, publication destination and physical cartridge actions require separate decisions in the handoff.
